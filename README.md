# Ayushkumar Portfolio

## Adding Your Own Images

1. Put your image in the appropriate `public/media` folder.
2. Keep the same filename as the placeholder it replaces.
3. Restart the development server if necessary.
4. The website will automatically use the new image.

All media paths are centralized in `src/data/portfolio.ts`; React components do not hardcode image paths. To replace a dummy external URL, replace the relevant `https://example.com` value in that data file with the real URL.
